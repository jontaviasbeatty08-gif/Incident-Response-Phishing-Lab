# Incident Response – Phishing Investigation Lab

## Overview

Completed a hands-on incident response investigation involving a phishing email that targeted multiple hosts within a network.

## Objectives

- Investigate a suspected phishing campaign
- Identify the malicious email sender
- Determine the attack vector
- Identify affected devices
- Analyze the execution timeline
- Identify malicious processes and activity
- Document the incident investigation

## Investigation

The investigation involved analyzing the timeline of events following a phishing email.

The timeline showed activity involving:

- explorer.exe
- chrome.exe
- File Downloaded
- Payslip.pdf
- PowerShell.exe
- Malicious DNS Query

## Skills Demonstrated

- Phishing investigation
- Incident response
- Timeline analysis
- Endpoint investigation
- Malware execution analysis
- PowerShell investigation
- DNS activity analysis
- Security incident documentation
